# Leycon Autos
1. Install Node.js (v18+), then in this folder run: `npm install`
2. Start: `ADMIN_PASSWORD=yourStrongPassword npm start` (Windows: `set ADMIN_PASSWORD=yourStrongPassword && npm start`)
3. Site: http://localhost:3000   Admin: http://localhost:3000/admin.html
4. Replace the WhatsApp number: `WA` in public/index.html (already set to 08166730041).
Data is saved in data.json, photos in public/uploads. Deploy on Render/Railway/a VPS (needs persistent disk).
